Coffee Sales Dashboard

An interactive Excel dashboard built from 1,000 coffee order records covering January 2019 to August 2022. The dataset includes customer, product, coffee type, roast type, size, country, quantity, pricing, and sales information. Slicers and a timeline filter every chart at once.

How it was built

Excel skills used

XLOOKUP / lookup functions
Combined customer and product information from separate tables into the order data.
Pivot tables
Analyzed sales by country, coffee type, roast type, size, and customer.
Pivot charts
Visualized sales trends over time and comparisons across countries and customers.
Slicers & timeline
Interactive filtering by roast type, size, loyalty card status, and order date. Every chart updates together.
Data cleaning & formatting
Organized the raw order data and calculated sales for each line item.
Closer look

Charts in detail

A note on the data: the workbook has 1,000 order rows but 957 unique Order IDs, because some orders contain more than one product. Each row is a line item, so totals are summed across line items rather than counted per order. Customer names and contact details in the dataset are sample data, not real people.
